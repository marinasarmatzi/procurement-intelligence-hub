# 🏢 Procurement Intelligence Hub

### Enterprise Procurement Analytics Platform

An end-to-end Power BI portfolio project designed to provide executive visibility across procurement spend, supplier performance, savings delivery, contract exposure, and self-service analytics.

Built using Power BI, DAX, SQL, Power Query and Python-generated synthetic datasets inspired by real-world procurement reporting requirements.

## 🎯 Key Business Questions

- Where is procurement spend concentrated across suppliers, categories and regions?
- Which suppliers represent the highest procurement risk?
- How effectively are savings initiatives being delivered?
- Which contracts require renewal attention?
- How can business users self-serve procurement data exports?

---

## 🛠 Tech Stack

- Python (synthetic data generation)
- SQL (data modeling)
- Power Query (data transformation)
- DAX (KPIs and business logic)
- Power BI (reporting and visualization)

## 📌 Disclaimer

This project uses Python-generated synthetic datasets.

All suppliers, contracts, projects, financial figures and procurement activities are simulated for portfolio purposes while preserving realistic enterprise procurement reporting scenarios.
