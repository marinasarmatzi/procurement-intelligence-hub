🏢 Procurement Intelligence Hub

Enterprise Procurement Analytics Platform | Power BI Portfolio Project

A multi-domain procurement analytics solution designed to support executive decision-making across spend visibility, supplier management, savings performance, contract exposure, and self-service data exploration.

Built using Power BI, DAX, SQL, Power Query and Python-generated synthetic datasets inspired by real-world procurement reporting requirements and business-approved analytical scenarios.

📈 Project Impact

This project recreates a real-world enterprise procurement analytics environment based on business-approved reporting use cases.

The solution demonstrates end-to-end BI development, from Python-based synthetic data generation and dimensional modeling to interactive Power BI reporting and self-service analytics experiences.

⚠ Disclaimer

This portfolio project uses Python-generated synthetic datasets.

All data, suppliers, contracts, projects and financial figures are simulated for demonstration purposes while preserving realistic procurement reporting scenarios.

## Project Availability

The Power BI source file is not publicly distributed.
